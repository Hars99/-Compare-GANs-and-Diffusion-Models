# Comparative Study of GANs and Diffusion Models

This project presents a comparative analysis of two powerful generative models:

- **Generative Adversarial Networks (GANs)** – Example: StyleGAN2
- **Diffusion Models** – Example: OpenAI’s DALL·E

## Overview

The comparison is based on the following key parameters:

- **Image Quality**
- **Training Stability**
- **Diversity of Results**
- **Ease of Use**

## Sample Images

Two AI-generated images have been used for this comparison:
- One generated using a GAN (StyleGAN2 via ThisPersonDoesNotExist)
- One generated using a Diffusion Model (OpenAI DALL·E)
